# Interaction taxonomy

Full technique reference for the presentation-engagement skill. Costs assume ~30 participants
and a tested tool; double join time for rooms over 100 or first-time tools.

| Technique | One-line spec | Cost | Best job | Strengths | Risks / failure modes |
|---|---|---|---|---|---|
| Pulse poll (2-3 options) | Fast opinion or temperature check | 45-60s | Evidence, Activate | Cheap, sets participation norm early | Becomes wallpaper if repeated; binary questions on nuanced topics produce fake consensus |
| Multi-option poll (4-6) | Choice among real alternatives | 60-90s | Evidence | Reveals actual preference distribution | Leading option order effects; put "Other/unsure" in to break bias |
| Word cloud | Single word or short phrase from everyone | 60-90s | Activate, Evidence | Low stakes, shows room's surface area, great opener | Spammers repeat words; meaningless if answers must be more than one word |
| Prediction / reveal | Audience guesses a number/outcome; presenter reveals truth | 60-90s | Activate | Being wrong by a lot is delightful; primes memory for the real number | Only works when the true answer is genuinely counterintuitive; rehearse the reveal |
| Quiz / knowledge check | Retrieval practice with right/wrong answers | 90-120s | Retain | Strongest learning effect of any technique | Reads as a test: damages trust with execs, cold rooms, or late in a hostile session; keep stakes zero (no names, no scores) |
| Scale check (1-5 / slider) | Confidence, agreement, or readiness rating | 45s | Evidence | Gives the presenter a dial, not a switch | Results are performative if the presenter does not change the session based on them |
| Collected Q&A (anonymous) | Questions submitted throughout, answered in blocks | Ongoing, 3-7 min blocks | Evidence, Reorient | Surfaces the real questions; anonymity fixes politeness suppression | Deferred everything-to-end = silence; needs the presenter to seed the first question |
| Pair / group discussion prompt | 2-3 min structured talk on one question | 3-5 min (feels longer) | Reorient, Retain | Highest engagement per participant of anything here | Cannot scale past ~40; noisy rooms; introvert-heavy technical audiences may hate it — offer "or write one line" |
| Raise-hand / show-of-hands | Zero-tech poll | 15-30s | Evidence, Reorient | No tool risk at all | Not anonymous: sensitive topics get distorted; remote hybrid audiences are hard to read |
| Chat reply (remote) | Text answers in Zoom/Teams chat | 30-60s | Evidence | Works with zero extra tooling | Only the loud 10% show up; results are a sample of extroverts |

Join-friction note: any tool requiring a second app, account, or tab change pays a participation tax on every interaction. Slide-native extensions avoid the second-tab trap entirely; hosted link-out tools are fine but budget the extra 20-30s and the participation drop.

## Anonymity decision rule

Sensitive = anything where a socially-safe answer exists that differs from the true one: budget
cuts, tool criticism, leader evaluation, security posture, "do you understand this". Default those
to anonymous. Everything else is fine public, and public answers build room connection faster.

## Join-friction ladder (remote/hybrid)

QR/link to a page with no account ≈ 70-90% participation. Add an email gate → −20-30%. Add a
download → −50%. Add a 6-digit code typed on a phone → −30% and 40 seconds of dead air.
Under 100 participants, one link is enough; over 100, test the venue network.
